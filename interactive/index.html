How these fit together

The pages are not standalone toys. Each one is the visual half of a module you can read and a notebook you can run.

learnai/ the implementation — readable, shape-annotated, tested notebooks/ build it up one cell at a time, on real data interactive/ the same mechanism, but you can grab it and move it

Pages that show real model internals read a file under data/ generated by make data, which trains a small GPT and dumps its tensors through learnai.export. Until you run it, those pages fall back to built-in sample values and say so.
