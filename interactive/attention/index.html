One query token, all the way through

Click any token to make it the query. This is a single row of the attention matrix — the token asks a question, every token answers, and the answers get averaged.

score(q, kⱼ) = q · kⱼ / √d

Raw compatibility. Can be any real number, positive or negative.

weightⱼ = softmax(score)ⱼ  →  Σ weightⱼ = 1

The whole matrix

Row i is the distribution token i attends with; every row sums to 1. Hover a cell for the exact weight. Turn on the causal mask and the upper triangle vanishes — that single change is the whole difference between BERT and GPT.

Why divide by √d?

Dot products of random vectors grow like √d. Feed those into softmax and it saturates — one weight goes to 1, the rest to 0, and the gradient dies. The curves below are measured live: random Q and K at each width, attention entropy averaged over rows. Higher entropy = the head is still looking at more than one place.

Unscaled, entropy collapses toward 0 as the head gets wider: by d = 256 the softmax is a hard argmax and ∂loss/∂score ≈ 0 everywhere. Scaled, entropy stays flat — the head keeps a usable gradient at any width.

This is why the paper calls it scaled dot-product attention. It is one / math.sqrt(d_k) and without it deep Transformers do not train.

Try it: turn off ÷ √d above and watch the weight bars in the first panel snap to a single spike.

The same mechanism, in a model that learned something

These maps come from a 4-layer character-level GPT trained on tinyshakespeare, captured with learnai.interp.capture_attention and written out by tools/build_data.py. Nothing is hand-designed here — this is what gradient descent produced.

What to look for. Sweep the heads and you will find the recurring shapes: a diagonal (attends to itself), a sub-diagonal (the previous-token head — the same behaviour built by hand at the top of this page), a bright first column (an attention sink, where a head parks when it has nothing to do), and vertical stripes on delimiters like the newline.
