What it looks like

What the attention score sees

The positional contribution to score(i, j) for every pair of positions, content held fixed. This is the diagnostic that matters: a scheme that encodes relative distance shows constant diagonals — the value depends only on i − j, not on where in the sequence you are.

Does it depend only on distance?

Each line is one query position, plotted against how far back it is looking. If the lines lie on top of each other, the positional effect is relative. If they scatter, absolute location still matters. A flat line also overlaps, but carries no position signal at all — so overlap is necessary, not sufficient.
